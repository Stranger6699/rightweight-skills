## Pi tool mapping

Pi's built-in tools are normally `read`, `write`, `edit`, and `bash`, with
optional `grep`, `find`, and `ls`. Pi has native skills but no universal `Skill`
tool: load a relevant `SKILL.md` with the native skill system or `read` it
directly.

Subagents and task lists are optional Pi companion capabilities. If they are
missing, do the work inline and track multi-step work in a plan or `TODO.md`;
never invent `Task` or `TodoWrite` calls.
